Estrutura da planilha

Cada linha representa um item de custo. A coluna grupo define em qual categoria o item será inserido automaticamente.

Fontes de dados compatíveis
Microsoft Excel
Exporte como .xlsx ou .xls. Certifique-se que a primeira linha contém os cabeçalhos.
CSV genérico
Qualquer sistema que exporte CSV — ERP, WMS, planilhas Google. Separador vírgula ou ponto-e-vírgula.
Power BI
Use "Exportar dados" em qualquer visual de tabela do Power BI e importe o .xlsx gerado.
Word / Outros
Copie a tabela para o Excel, ajuste os cabeçalhos e exporte como .xlsx antes de importar.

Usar no GitHub

Este arquivo é um HTML completamente standalone — sem dependências locais. Para publicar no GitHub Pages:

  1. Faça upload do arquivo tradeprice.html para um repositório
  2. Renomeie para index.html ou configure o arquivo-raiz no GitHub Pages
  3. Ative GitHub Pages em Settings → Pages → Source → main branch
  4. Acesse pelo link seu-usuario.github.io/repo
