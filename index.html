Publicar no GitHub Pages

Arquivo 100% standalone, zero dependências locais:

  1. Upload de tradeprice.html para o repositório
  2. Renomeie para index.html
  3. Ative GitHub Pages em Settings → Pages → Source → main
  4. Acesse em usuario.github.io/repositorio
 Instalável como PWA no Android e desktop via Chrome — botão aparece no menu lateral ou na barra de endereço.
