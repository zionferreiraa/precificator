Estrutura da planilha

Cada linha representa um item de custo. A coluna grupo define em qual categoria o item será inserido.

* grupo * nome * custo_unitario quantidade categoria

* campos obrigatórios

Fontes compatíveis
Microsoft Excel
Exporte como .xlsx ou .xls. Primeira linha deve conter os cabeçalhos.
CSV genérico
Qualquer ERP, WMS ou planilha Google que exporte CSV. Vírgula ou ponto-e-vírgula.
Power BI
Use "Exportar dados" em qualquer visual de tabela e importe o .xlsx gerado.
Word / Outros
Copie a tabela para o Excel, ajuste cabeçalhos e exporte como .xlsx antes de importar.

Publicar no GitHub Pages

Este arquivo é 100% standalone — zero dependências locais. Para hospedar no GitHub Pages:

  1. Faça upload de tradeprice.html para um repositório
  2. Renomeie para index.html
  3. Ative GitHub Pages em Settings → Pages → Source → main branch
  4. Acesse em usuario.github.io/repositorio
 O app pode ser instalado no Android e desktop via Chrome como PWA — botão de instalação aparece na barra lateral após abrir no navegador.
